# UI Specification – AgroSynapse Dashboard

## Overview
The AgroSynapse dashboard presents insights from processed survey data with an emphasis on agricultural performance, soil health, and adoption metrics.

## Core Pages
### Overview
- KPI cards: total farmers, total yield, avg yield per ha, avg soil pH
- Map of farmer distribution
- Trend line: yield over time

### Soil Analysis
- pH distribution histogram
- Nutrient scatter: nitrogen vs yield
- Soil test table with filters

### Adoption & Practices
- Practice adoption rates by district
- Yield comparison by practice

### ML Insights
- Model performance metrics (RMSE, MAE)
- Feature importance chart
- Prediction vs actual plot

## Global Interactions
- Filters: season, crop, district, soil type
- Hover tooltips for charts
- Click-to-filter on map and charts

## Visual Style
- Clean data-first layout
- Consistent typography and spacing
- Accessible color palette for agronomic data

## Data Refresh
- Refresh indicator for latest pipeline run
- Metadata panel showing last ingestion time
